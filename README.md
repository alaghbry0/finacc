# 🧮 المُحاسِب الشخصي — FinAcc

**تطبيق أندرويد عربي كامل (RTL) للمحاسبة وإدارة المخزون — يعمل أوفلاين 100%**

مصمَّم للتجار وأصحاب المتاجر الصغيرة والمتوسطة: فواتير، صندوق، عملاء وموردون، مخزون، أقساط، شيكات، تقارير — كل شيء على هاتفك وبدون إنترنت، وبدون أي اشتراكات.

### خطوات التثبيت على أندرويد 📱

1. افتح رابط التحميل من **متصفح هاتفك** وحمّل الملف.
2. افتح الملف من شريط الإشعارات أو مجلد التنزيلات.
3. سيسألك أندرويد السماح بـ«**التثبيت من مصادر غير معروفة**» لهذا المتصفح/التطبيق — اسمح به (مرة واحدة فقط).
4. اضغط «تثبيت» ثم افتح التطبيق.
5. **أول تشغيل**: تهيئة قصيرة (اسم المنشأة، العملة، رقم سري PIN من 4 أرقام) — بعدها يبدأ العمل مباشرة.

> 💡 التطبيق لا يطلب أذونات حساسة، ولا يرسل بياناتك لأي خادم — قاعدة البيانات كلها داخل هاتفك، مع نسخ احتياطي يمكنك تصديره ومشاركته (واتساب/ملف).

## ✨ الميزات (الإصدار 1.0.0)

**المبيعات والمشتريات**
- فاتورة مبيعات نقدي/آجل بترقيم تلقائي INV-، بحث أصناف، خصم، وطباعة/مشاركة PDF وواتساب
- فواتير مشتريات PR- ومرتجعات مبيعات/شراء RVT-/RVP- بمرجعية كاملة للمستند الأصلي

**النقدية والحسابات**
- صندوق نقدي بكل الحركات، سندات قبض/صرف بتخصيص ذكي على الفواتير
- كشف حساب تفصيلي لكل عميل/مورد مع الأرصدة والتقادم
- خطط الأقساط للبيع الآجل (تقسيم تلقائي، تحصيل جزئي/تعجيل، إعادة جدولة)
- إدارة الشيكات (محصَّلة، مرتدة، مؤجلة) بأثر مباشر على الصندوق

**المخزون**
- أصناف بوحدات قياس وحد أدنى/أقصى وتكلفة متوسط مرجّح (WAC)
- تعدد المخازن، جرد فعلي يقفل الأرصدة ويسجل الفروقات بقيمتها
- تنبيهات تحت الحد الأدنى، بطاقة صنف كاملة بالرصيد التراكمي

**التقارير**
- مبيعات حسب العميل/الفئة/الصنف/اليوم مع مقارنة بالفترة السابقة
- حركة مخزون، بطاقة صنف، تحت الحد الأدنى، أعمار الديون
- لوحة 30 يوماً بخريطة حرارية وتفاعل باللمس

**النظام**
- نسخ احتياطي مصدَّق ببصمة + استعادة ذرّية (يدوي وجدول يومي/أسبوعي)
- إعدادات كاملة: بيانات المنشأة، العملة والمنازل، الضريبة، حدود الائتمان، الأمان (PIN + قفل تلقائي)
- عربي RTL بالكامل، يعمل أوفلاين، بيانات محلية 100%

## 🧰 التقنيات

| الطبقة | التقنية |
|---|---|
| التطبيق | React Native + Expo SDK 54 (Android native، هرمس) |
| اللغة | TypeScript صارم |
| قاعدة البيانات | SQLite أصلي (expo-sqlite natives) فوق مخطط Drizzle |
| البنية | طبقة Domain نقية قابلة للاختبار + شاشات Expo Router |
| الاختبارات | 498 اختبار وحدة للمنطق المالي والمخزني |
| المعاينة أثناء التطوير | قشرة Next.js بإطار هاتف (iframe إلى تصدير الويب RN) |

## 🗂 بنية المشروع

```
finacc-mobile/          # تطبيق React Native (Expo)
├── app/                #   الشاشات (Expo Router): بيع، شراء، مخزون، نقدية، تقارير...
├── src/
│   ├── domain/         #   منطق الأعمال النقي (فواتير، نقدية، أقساط، جرد...) + اختبارات
│   ├── db/             #   المخطط واستعلامات SQLite
│   ├── components/     #   مكونات الواجهة المشتركة
│   └── i18n/           #   النصوص العربية
├── drizzle/            #   DDL قاعدة البيانات
└── scripts/            #   سكربتات البناء
public/rn/              # تصدير الويب للمعاينة (يغذي iframe القشرة)
src/                    # قشرة المعاينة Next.js (صفحة واحدة بإطار هاتف)
docs/                   # وثيقة المواصفات SRS
```

## 🔧 للتطوير محلياً

```bash
# تطبيق RN
cd finacc-mobile
bun install
npx expo start            # أو بناء الويب: bash scripts/build-rn-web.sh

# قشرة المعاينة (اختياري)
bun install
bun run dev
```
